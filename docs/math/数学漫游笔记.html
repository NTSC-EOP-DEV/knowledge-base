2形式化数学：Lean

Lean 是一个交互式定理证明器，基于依赖类型论：命题写成"类型"，证明就是构造该类型的"项"。

import Mathlib
example (u v : ℝ × ℝ) (h : u.1 * v.1 + u.2 * v.2 = 0) :
    (u.1 + v.1) ^ 2 + (u.2 + v.2) ^ 2
      = (u.1 ^ 2 + u.2 ^ 2) + (v.1 ^ 2 + v.2 ^ 2) := by
  nlinarith [h]

example (a b : ℝ) : (a + b) ^ 2 = a ^ 2 + 2 * a * b + b ^ 2 := by ring

上面第一个例子把勾股定理翻译成代数恒等式，再交给代数引擎 nlinarith 完成——这正是几何代数化在形式化时代的延续。

3黎曼猜想

ζ(s) = Σn=1..∞ 1 / ns  (Re(s) > 1)
ζ(s) = Πp 素数 1 / (1 − p−s)

欧拉乘积把"素数"与"求和"直接连在一起，是素数信息进入解析方法的入口。

解析延拓与函数方程：ζ 可被唯一地延拓到整个复平面（除 s=1 一个极点）：

ζ(s) = 2s πs−1 sin(πs/2) Γ(1−s) ζ(1−s)

平凡零点

由 sin(πs/2)=0 强制，位于 s = −2, −4, −6, …（负偶数）。

非平凡零点

全部落在临界带 0 < Re(s) < 1 内。

黎曼猜想：所有非平凡零点的实部都等于 ½，即全部落在临界线 Re(s)=½ 上。它精确刻画了素数分布的误差项。

4从实变到复变：多一个维度带来什么

在实数域，"可导"只是好函数的一个子类（光滑 ≠ 解析）；在复数域，三件事塌缩成同一件事：

复可导  ⟺  解析  ⟺  可展成收敛幂级数

原因是复极限要求 h 沿所有复方向趋于 0 时一致，这给出柯西–黎曼方程：

∂u/∂x = ∂v/∂y,   ∂u/∂y = −∂v/∂x

并直接推出唯一性定理：解析函数在任意小邻域上的取值，唯一决定它在整个连通区域上的取值——局部决定整体。复数世界的规则不是更松，而是更硬。

5复数的几何

一、乘以 i ＝ 逆时针旋转 90°

i·1 = i，把 (1,0) 送到 (0,1)。于是 i² ＝ 旋转两次 90° ＝ 旋转 180° ＝ 乘以 −1。所以 i² = −1 不是硬规定，而是"直角转两下＝掉头"的代数写法。i³=−i，i⁴=1，周期为 4。

二、加法是平移，乘法是相似

乘法则是旋转 + 拉伸（相似变换），不动原点。一句话定义：

ℂ ＝ 给 ℝ² 再装上一个乘法（等价于选定一个"逆时针 90°"的旋转算子 i）。向量只有加法，没有天然的乘法；复数就是"补上乘法"的那个平面。

三、极坐标 / 指数式

z = a + bi = r eiφ,   r=|z|, φ=arg z,   eiφ = cos φ + i sin φ
(r₁,φ₁)·(r₂,φ₂) = (r₁r₂, φ₁+φ₂)

即模长相乘、辐角相加——指数律 eiαeiβ = ei(α+β) 的几何含义。

四、两套坐标：没有免费午餐

运算直角式 a+bi指数式 r eiφ
加法 z₁+z₂✅ 分量直接相加❌ 需和差化积
乘法 z₁·z₂❌ 要展开四项✅ (r₁r₂)ei(φ₁+φ₂)
乘方 zⁿ❌ 二项式展开✅ rⁿ einφ（棣莫弗）
n 次方根❌ 难写✅ 均匀落在圆上
旋转❌ 乘旋转矩阵✅ 辐角直接加
唯一性✅ 一一对应❌ φ 模 2π；z=0 无定义

直角式为加法而生，指数式为乘法而生。指数式强，是因为它把乘法变成了辐角相加——和 ln 把"乘"变"加"是同一机制；代价是丢了唯一性（多值、原点特殊）。

五、共轭与保角

共轭 z̄ = a − bi = r e^(−iφ)：沿实轴镜像。因为乘法只做旋转 + 等比伸缩，解析函数的导数（非零处）局部也是"旋转 + 伸缩"，即保角映射。

6复变函数的性质与应用

洛朗级数：在奇点附近，解析函数可展成含负幂的级数 f(z)=Σ aₙ(z−z₀)ⁿ。据此把孤立奇点分三类：

类型洛朗展开特征例子
可去奇点无负幂项sin z / z 在 z=0
极点（m 阶）有限个负幂项1/z² 在 z=0
本性奇点无穷多个负幂项e1/z 在 z=0

零点与极点互为倒数镜像：f 的零点 ↔ 1/f 的极点。

留数定理

把实轴上的困难积分化为复平面内的留数求和。

共形映射

把复杂区域映成标准区域（如上半平面 ↔ 单位圆），求解流体、电场边值问题。

色散关系

由因果性 + 解析性，把折射率的实部与虚部联系起来。

保角性

导数非零处局部保角，是复分析几何图像的核心。

7解析延拓

ζ 的级数只在 Re(s)>1 收敛，可非平凡零点全在不收敛的临界带里——不延拓就无从谈起。

1/(1−z) = 1 + z + z² + ⋯ (|z|<1)  →(唯一延拓)→  1/(1−z) (z≠1)

唯一性：两解析函数若在有聚点的集合上相等，则在整连通区域上相等——延拓若存在，只有一种。

用途：定义特殊函数（Γ、ζ）在全平面的值；给发散级数"定值"（1+2+3+⋯ = ζ(−1) = −1/12）；物理中的 QFT 正则化/重整化、Wick 转动、S 矩阵的解析性与极点（极点 ＝ 束缚态/共振）。
代价与结构：可能遇到自然边界；多值函数（如 log z）需要分支割线与 Riemann 曲面——正是指数式丢掉的唯一性在复分析里的具体偿还。

8复变函数与物理世界

复数在量子力学里是"本体"吗？

  • 波函数不是物质，它是对微观状态的一种描述；
  • 微观世界的运行规则恰好在数学结构上最自然地用复数描述；
  • 精确表述：整体相位不可观测（描述冗余），相对相位可观测（物理）。
"复数不是物质，但也不是随便的描述——它是相位的代数。"

数学高自由度 vs 物理强约束（两层结构）

语法层：自由

数学可以定义任意规则。

推导层：被迫

一旦选定规则，结论就被锁死。物理约束作用在这一层：解析性、幺正性、对称性（+ Noether）、局域性 + 洛伦兹 + 幺正。

因此 Wigner"数学不合理的有效性"之谜可重述为：被物理用上的，只是数学中满足强约束的极小一撮。

幺正性（直观版）

幺正 U 满足 U†U = I：保内积、保范数、可逆，几何上像"旋转"。演化 U(t)=e−iHt（Stone 定理）确定、可逆；而测量是投影/塌缩，非幺正、随机、不可逆。

10微分几何入门

流形：局部看起来像欧几里得空间的拓扑空间（局部可放"坐标卡"，坐标卡 + 转移映射 ＝ 图册；维数是局部概念）。核心工具链：

  1. 切空间 TPM：点 P 处的"速度向量"组成的线性空间；
  2. 向量场 / 微分形式：每点光滑地取切向量 / 余向量；
  3. 度规 g：每点定义内积，测长度与角度；
  4. 联络：定义"平行移动"，从而比较不同点的向量；
  5. 曲率：把向量沿闭合回路平行移动一圈后的偏差（holonomy）——测量"绕一圈转了多少"。
球面局部像平面，整体却弯曲；曲率是"局部平坦性在整体上的破缺"。

12实函数为何"复化"

先纠正直觉：很多人把"实函数 + 显式公式"当原始，但常常恰恰相反——复函数才是本尊，实函数只是它在实轴上的一刀切片。

  1. 延拓被唯一性逼出来：复真身（若存在、区域连通）只有一种；换任何别的复公式都会违背原函数或丢掉解析性。
  2. 三合一：ℂ 上"复可导 ⟺ 解析 ⟺ 幂级数"，实世界的"好函数子类"升级为"全局硬约束"。
  3. 实轴的谜团藏在复平面：1/(1+x²) 处处光滑，幂级数收敛半径却只有 1——因为 ±i 处有极点，收敛半径 ＝ 到最近奇点的距离。
  4. 母函数显形：ez 一出，sin z、cos z、sinh z、cosh z 都成为 eiz 的线性组合。
性质判断标准
发现（唯一延拓）复数是真身拆回实数会丢信息 / 拆不回去（如 ζ 零点、收敛半径的成因）
记号便利复数是工具拆回实数完全等价，只是写起来麻烦（如相量法、复频率、FFT）
真正"人为"的只有复数乘法规则这一条；一旦写下，其余全是被逼出来的后果。复化多数是发现真身，不是数字游戏——但要分清哪些是发现、哪些只是记号便利。

13数论与素数

算术基本定理：每个大于 1 的整数都能唯一地拆成素数之积，如 60 = 2·2·3·5。于是素数是整数的"乘法原子"，整数在乘法下的结构完全由素数决定。

加法：温和

相邻整数差恒为 1，规则可预测。

乘法：野生

复杂度全压在素数分布上；定义极简（只能被 1 和自己整除），行为极深。

素数是整数"加法结构"与"乘法结构"之间的接口（透过 log / ζ 相连）。

素数规律在物理中是否起特殊作用

基本结论：没有哪条物理定律是由素数的算术决定的。素数不是物质、不是力。但存在三层真实连接：

层级内容性质
最强·谱Montgomery–Odlyzko：ζ 非平凡零点间距统计 ≈ 量子混沌能级间距统计（GUE）；Hilbert–Pólya：零点 = 某自伴算子的谱；Selberg 迹公式：闭测地线长度 ↔ 拉普拉斯谱真实且深刻
工程·生物Shor 算法把大数分解化为周期查找；周期蝉 13/17 年避开捕食者周期真实，非自然律
需澄清不是"物理依赖素数"，而是素数分布与量子谱共享同一统计普适类常见误读
桥搭在统计与谱上，不在算术本体上。这正是黎曼猜想为何不止是数论——Hilbert–Pólya 想找一个算子，让素数零点成为它的能级。

14核心洞察汇总

  1. 形式化 = 可审计：Lean 让证明能被机器逐行核验，但"会验证"≠"会理解"。
  2. 复变的质变：复可导 ⟺ 解析 ⟺ 幂级数；苛刻的极限要求换来"局部决定整体"。
  3. i 是旋转的生成元：i²=−1 是"直角转两下＝掉头"的代数写法。
  4. 加法是平移，乘法是相似：ℂ ＝ ℝ² 加上一个乘法。
  5. 换坐标让运算对角化：直角式为加法、指数式为乘法；ln 把乘变加是同一招。
  6. 延拓是被逼的唯一选择：实函数是切片，复函数是本尊。
  7. 复数不是本体：量子力学里它是"相位的代数"。
  8. 数学自由在语法层，被迫在推导层：物理用到的只是数学的一小撮。
  9. 素数 = 乘法原子：与物理的桥搭在统计与谱上。
  10. 诚实划界：区分"发现"与"记号便利"，是评价一切"数学迁移"的通用标尺。
